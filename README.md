# Telegram-бот для приёма заявок (aiogram 3 + SQLite)

Бот принимает заявки от клиентов, сохраняет их в базу и присылает администратору с кнопками смены статуса. Клиент видит свои заявки и получает уведомление, когда статус меняется. Подходит как основа для бота мастерской, студии или небольшого сервиса.

[Заявка у администратора](docs/admin.png)


## Возможности

**Для клиента**
- Пошаговая форма: имя → телефон (кнопкой «Отправить мой номер» или вручную) → тема → описание → проверка → отправка
- Проверка введённых данных на каждом шаге, отмена в любой момент (`/cancel` или кнопка «Отмена»)
- «Мои заявки»: список последних заявок со статусами и детали каждой
- Уведомление в Telegram при смене статуса заявки

**Для администратора**
- Мгновенное сообщение о новой заявке с данными клиента
- Кнопки статусов: «В работу», «Выполнена», «Отклонить»
- Команда `/admin`: список новых заявок
- Закрытые заявки защищены от повторного изменения

**Надёжность**
- Доступ к административным функциям только по списку `ADMIN_IDS`
- Весь пользовательский текст экранируется перед выводом (защита от HTML-разметки)
- Токен и настройки хранятся в `.env`, а не в коде

## Как это устроено

```
Клиент → форма (FSM: имя → телефон → тема → описание → подтверждение)
       → SQLite (таблицы users, applications)
       → уведомление администратору → смена статуса → уведомление клиенту
```

| Файл | Назначение |
|---|---|
| `bot.py` | обработчики сообщений и кнопок, форма заявки, запуск бота |
| `db.py` | работа с базой SQLite (aiosqlite): схема и запросы |
| `keyboards.py` | клавиатуры и кнопки |
| `config.py` | настройки, категории заявок, статусы |
| `.env.example` | пример файла с настройками |

## Стек

Python 3.11+, [aiogram](https://docs.aiogram.dev/) 3.13+, aiosqlite, python-dotenv, SQLite.

## Установка и запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) командой `/newbot` и скопируйте токен.
2. Скопируйте `.env.example` в `.env` и заполните:
   ```
   BOT_TOKEN=токен_от_BotFather
   ADMIN_IDS=ваш_telegram_id
   ```
   Свой id можно узнать у бота [@userinfobot](https://t.me/userinfobot).
3. Создайте виртуальное окружение и установите зависимости.

   Windows:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
   Linux / Raspberry Pi:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
4. Запустите:
   ```bash
   python bot.py
   ```
   База `data/bot.db` создаётся автоматически при первом запуске.

## База данных

```sql
users(id, username, full_name, created_at)
applications(id, user_id, name, phone, category, description, status, created_at, updated_at)
```

Посмотреть данные можно в [DB Browser for SQLite](https://sqlitebrowser.org/): откройте файл `data/bot.db`. Файл базы в репозиторий не попадает, потому что в нём телефоны клиентов.

## Настройка под себя

В `config.py`:
- `CATEGORIES`: темы заявок, которые видит клиент
- `STATUSES`: статусы заявки

Тексты сообщений находятся в `bot.py`, названия кнопок в `keyboards.py`.

## Что можно доработать

- Запуск на сервере (VPS или Raspberry Pi) как системная служба, чтобы бот работал круглосуточно
- Хранение состояния форм в Redis вместо памяти, чтобы они не терялись при перезапуске
- Экспорт заявок в таблицу (Excel или Google Таблицы)
- Фильтры и поиск по заявкам для администратора
